# Security policy

Please report vulnerabilities in mcp-sdk-audit itself privately through GitHub's
[private vulnerability reporting](https://github.com/garag0l/mcp-sdk-audit/security/advisories/new),
not through public issues.

Vulnerabilities in the MCP SDKs belong upstream:
[typescript-sdk](https://github.com/modelcontextprotocol/typescript-sdk/security),
[python-sdk](https://github.com/modelcontextprotocol/python-sdk/security),
[go-sdk](https://github.com/modelcontextprotocol/go-sdk/security).
